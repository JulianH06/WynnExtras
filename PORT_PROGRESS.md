## Upstream-merge workflow (recurring)
1. `git fetch upstream` (bzw. `git fetch --all`)
2. One-time per clone: `git config merge.wtshim.driver 'tools/merge-wtshim.sh %O %A %B'`
3. `git merge upstream/1.21.11` — driver absorbs import churn in .java files
4. Residual conflict hotspots: `fabric.mod.json` (wynntils-dependency must STAY removed; entrypoints/mixins lists), `build.gradle`/`gradle.properties` (shadow/EventBus setup)
5. `bash tools/relocate-wynntils-shim.sh` (idempotent — rewrites newly added upstream files)
6. Build → compile errors mean upstream uses Wynntils APIs missing in the shim → copy from the Wynntils repo, re-run script, fill in
7. `runClient` smoke → commit
