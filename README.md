## In-game WynnBuilder

Open with `/we wynnbuilder`.

- Plan builds with equipment, powders, skill points, ability trees, tomes and aspects.
- Search items and ingredients with WynnAtlas.
- Create and preview crafted items with WynnCrafter.
- Save builds and switch between multiple tool tabs.

Still in beta. Ability Boosts and special Major ID effects aren't implemented.
